# 스윙 신호 백테스트 (한국 대형주)

## 지금 상태

- `kr_swing_backtest.py`: easy-stock의 `swing_backtest.py`(미국 주식)를 한국 시장용으로 옮기고, 조합 규칙과 임계값 스윕을 더했어요.
- 계산 로직은 단위 테스트(`tests/`)와 가짜 데이터로 점검했어요.
- 2026-10-04 야후 파이낸스 실데이터(2011-01 ~ 2026-10, 48종목 + 코스피)로 돌렸어요. 전체 표는 [swing-backtest-kr-results.md](swing-backtest-kr-results.md), 요약과 추천은 아래 "결과 요약"에 있어요.
- 야후가 한꺼번에 받으면 429(요청 과다)를 줘서, 다운로드는 종목별로 1.5초씩 쉬고 실패하면 간격을 늘려 최대 5번 다시 시도해요.

## 검증하는 규칙

| 규칙 | 매수 (종가 기준, 다음 날 시가 체결) | 매도 |
|---|---|---|
| 눌림목 | 200일선 위 종목이 RSI2 < 10 | 종가가 5일선 위 또는 10거래일 경과 |
| 돌파 | 종가가 직전 20일 최고가 돌파 | 종가가 직전 10일 최저가 아래 |
| 조합: 돌파 후 눌림 | 최근 10일 안에 20일 신고가를 낸 종목이 RSI2 < 10 (200일선 위) | 눌림목과 같음 |

각 규칙을 "코스피가 200일선 위일 때만 새로 매수" 필터 유무로 두 번씩 돌려요. 두 신호는 같은 날 동시에 나올 수 없어서(신고가 날은 RSI2가 높아요) 조합은 "돌파 뒤 첫 눌림"으로 정의했어요.

## 가정

- 종목: 2015년 말 코스피 시가총액 상위권 48개. 지금 잘나가는 종목을 고르지 않으려고 과거 기준으로 골랐지만, 그 뒤 상장폐지·합병된 종목은 데이터가 없어 빠져요.
- 비용: 수수료 0.015%(매수·매도 각각), 매도 시 세금 0.20%, 슬리피지 0.05%(기본) / 0.2%(보수적). 세율은 해마다 바뀌어서 `COSTS`에서 조정하세요.
- 최대 5종목, 종목당 자본 1/5, 놀고 있는 돈은 연 2.5% 이자.
- 앞 구간(2011~2018)에서 고른 임계값이 뒤 구간(2019~)에서도 통하는지를 같이 봐요. 앞 구간 1등이 뒤 구간에서 순위가 크게 밀리면 과최적화예요.
- `--capital 300000`을 주면 30만 원 계좌에서 정수 주식만 사는 경우도 계산해요. 종목당 6만 원이라 비싼 종목은 신호가 나도 못 사요.

## 실행

```bash
pip install pandas numpy yfinance
python kr_swing_backtest.py --capital 300000 --out docs/swing-backtest-kr-results.md
```

처음 실행하면 `data/kr_daily.csv`에 시세를 저장하고, 다음부터는 그 파일을 써요. 다른 출처 데이터는 `--csv 파일`로 넣으면 돼요(열: `date,ticker,open,close`, 코스피 지수는 `ticker=^KS11`).

## 결과 읽는 법

1. **보유보다 나은가**: "48개 같은 비중 보유"와 "코스피 지수 보유" 줄보다 연평균·샤프가 높아야 규칙을 쓸 이유가 있어요. 미국 대형주 45개에서는 두 규칙 모두 그냥 보유(+13.9%)에 못 미쳤어요.
2. **보수적 비용에서도 남는가**: 눌림목은 거래가 잦아서(연 100회 이상) 슬리피지에 특히 약해요.
3. **뒤 구간에서도 통하는가**: 스윕 표의 "앞 구간 1등 설정의 뒤 구간 순위"가 위쪽이어야 해요.
4. **소액 계좌에서 실제로 체결되는가**: "돈이 모자라 못 산 신호"가 많으면 30만 원으로는 백테스트 성과를 재현할 수 없어요.

- 눌림목·조합의 15년 전체 수익은 거의 다 앞 구간(2011~2018, 횡보장)에서 나왔어요. 2019년 이후에는 기본 설정 규칙 중 어느 것도 그냥 보유(+15.6~18.0%)를 못 따라갔어요.
- 눌림목은 연 167번 거래해서 슬리피지를 0.05%에서 0.2%로만 올려도 연 +16.3%가 +5.2%로 떨어져요.
- 돌파는 15년 내내 손해였어요. 승률 32%에 이익 한 번(+8.9%)이 손실 두 번(-5.3% × 2)을 못 메꿔요.
- 30만 원 계좌에서 조합 + 코스피 필터는 연 +8.0%, 최대 낙폭 -7%였어요. 다만 신호의 55%(956번)는 종목당 6만 원이 모자라 못 샀고, 실제 체결된 건 769번이에요. 그래서 위 백테스트 숫자를 그대로 재현할 수는 없어요.

## 임계값 추천 (앞 구간에서 고르고 뒤 구간에서 확인)

| 규칙 | 추천 | 근거 |
|---|---|---|
| 눌림목 + 코스피 필터 | `th=10 → 15~20`, `max_hold=10 → 20`, `exit_ma=5` 유지 | 앞 구간 1등(th=20, max_hold=20)이 뒤 구간에서도 45개 중 2등 (뒤 구간 연 +5.7%, 기본값은 +4.4%). 이웃 설정(th=15)도 +6.0%로 비슷해서 우연이 아니라고 봐요. |
| 눌림목 (필터 없음) | 바꾸지 말고 쓰지도 않기 | 앞 구간 1등(exit_ma=3)이 뒤 구간 41/45등 (연 -7.2%, 낙폭 -64%). 전형적인 과최적화예요. |
| 조합 + 코스피 필터 | 기본값 유지 (`th=10, n=20, within=10`) | 앞 구간 1등(th=20, n=55)은 뒤 구간 8/18등, 연 +6.2%로 기본값(+7.2%)보다 못해요. |
| 조합 (필터 없음) | 바꾸지 않기 | 앞 구간 1등이 뒤 구간 17/18등이에요. |
| 돌파 | 쓰지 않기 | 앞 구간에서는 모든 설정이 마이너스였어요. 필터를 붙이면 뒤 구간 숫자가 플러스로 바뀌지만, 앞 구간에서는 고를 근거가 없었어요. |

**결론:** 30만 원으로 규칙을 하나만 쓴다면 **조합 + 코스피 200일선 필터 (기본값)**예요. 규칙 중에 낙폭이 가장 작고(-18%) 뒤 구간 성과도 가장 좋았어요(+7.2%). 하지만 2019년 이후에는 48종목을 같은 비중으로 그냥 들고 있는 쪽(+15.6%)이 두 배 넘게 벌었어요. 그러니 규칙은 "보유보다 덜 떨어지는 대신 덜 버는" 방어용으로 보고, 수익을 노린다면 보유가 기본이에요. 실데이터 표에서 눈에 띄는 이상치는 NAVER 2013년 분할과 HD한국조선해양 2017년 분할 정도였고, 결과를 바꿀 수준은 아니에요.

과거 성과가 미래를 보장하진 않아요.
