2026-10-24 사용자: "pr바로 올리지 말고 나한테 검수받고 한번에 올리자" (주간 리포트 디자인 다듬는 중에).
**Why:** 작은 수정마다 PR이 올라가면 확인·머지가 번거로움. 사용자가 직접 보고 고친 뒤 한 번에 받고 싶어 함.
**How to apply:** 변경은 브랜치에 커밋만 해 두고(푸시·PR 업데이트 X), 미리보기 사진(밝은·어두운 화면)을 /mnt/project-files/<기능>-preview/에 올려 스레드에 붙여서 검수받기. 사용자가 OK하면 그때 푸시/PR. 여러 PR은 [[MEMORY]]의 합치기 규칙대로 한 번에.
