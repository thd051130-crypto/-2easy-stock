2026-10-17 사용자가 "성과 칸 보기 좋게, 수익률 달력 맨 위, 내 규칙표 검증도 위로, 추천 종목은 너무 나열, 가상계좌 세로 줄여"라고 함.
- 성과 화면 순서(VIEWS.perf, site/app.js): 수익률 달력 → 내 규칙표 검증 → 가상계좌 → 보유 종목 → 추천 종목 성과 → 적립식 계산기 → 폭락 대비 → 매매 복기 → ETF 계좌 → 실전 전환 판정 → 목표 → 메모 → 점검 → 첫 계좌.
- 가상계좌: 금액 한 줄 + 숫자 3칸, 큰 그래프(화면 55%)는 '수익률 그래프'로 접음. 추천 종목 성과: 평균 숫자 3칸 + 최근 3개, 그래프·나머지 종목은 접음. 펼친 그래프는 localStorage perf_open에 기억, 펼칠 때 그림.
- 국장 성과 화면 7,795px → 6,548px. 기능 삭제 없음.

**How to apply:** 성과 화면에 새 칸은 위쪽 핵심(달력·규칙표·가상계좌) 아래에. 큰 그래프는 기본 접기. 관련 [[home-cleanup-pr64]], [[phone-dashboard]].
