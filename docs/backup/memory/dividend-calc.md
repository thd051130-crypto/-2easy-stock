2026-11-28 사용자 "내가 가진 주식 배당 계산기": 입력해 둔 종목만, 몇 주 모으면 최신 배당으로 얼마(세전/세후), 목표 배당금 → 보유 종목으로 포트폴리오(선택형), 그래프 없이 등락만, 현재 보유로 시작.
- 코드: site/js/divcalc.js (★ 도구 화면 LAZY, sw.js APP_JS·CACHE v9), PERF_TABS 키 "div" (자산 기록 다음). asset.js의 dvHold·dvHist·DV_TAX·dvFx 재사용. CSS `.dc-*`. 저장 localStorage divcalc {q,net,goal,amt,per,way} (BK_KEYS에도).
- 1년 배당 = 최근 1회 배당 × 1년 횟수(dvHist 길이) × 주 수. 최근 1회가 평소의 3배 넘으면 특별 배당일 수 있다고 보고 1년 계산은 평소 크기(삼성전자 9월 4,601원이 야후 자료에 있음).
- 직전 대비: returns.py가 r[7](13~24달 전 배당)을 새로 저장 → 1년 1회 종목도 비교. 데이터는 토요일 returns.py 돌아야 생김(그 전엔 '직전 기록 없음').
- 목표: '지금 비중 그대로'(보유 비율로 늘림) / '모자란 만큼 같은 돈씩'(가격 아는 종목만). 팔기는 안 함. '이 주 수를 위 계산기에 넣기'.
- 2차(11-28 사용자 "종목 누르면 화면 창"): 국장/미장 구역(구역 제목에 1년 합), 계산기엔 종목명만(가격·배당률은 창에), 주기 이모지 📅매달·🍀분기·🌗반년·🎁1년1번. 이름 누르면 아래에서 뜨는 창(#dc-pop, 뒤 화면 위치 그대로): 지금 가격·배당률, 배당락 달 12칸, 연도별 1주 배당 막대+전년 대비 %, 최근 5년 연평균·연속 늘림, 연도별 표, 배당 내역(직전 대비).
- 10년 배당 내역: returns.py가 paper/symbols/<시장>_divs.json 따로 저장 → stock_pages.py·all_stocks.py가 종목 파일 "divs"로 넣음(dashboard.py는 _divs.json 통째로 안 올림). 머지 뒤 첫 토요일 returns 실행 + 그다음 all-stocks·배포가 돌아야 창에 내역이 나옴(그 전엔 '토요일 뒤부터' 안내).
- 3차(11-28 사용자 "연도별·내역 간소화, 배당락 표기, 소수점, 고점 대비 20% 하락이면 매수 추천"): 연도별 표 없앰(막대로 충분), 최근 배당 4칸 + '전체 내역' 접기. 다음 배당락 = funds exdiv(확정) 또는 지난 1년 배당락 달로 'N월쯤'(예상), 줄·창에 표시. +/− 소수점 유지, 목표에 '소수점으로 사기(0.01주)'. 1년 최고점 대비(종목 파일 일봉, 없으면 _quotes q[4]) −20% 이하면 🛒 매수 신호 꼬리표(주황 wait 색) + 창에 '단순 규칙, 이유 확인' 안내 (DC_BUY).
