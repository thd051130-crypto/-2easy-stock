# 리포트팀 조사 지침 (사용자 작성, 2026-10-23)

리포트 자료를 만들 때 항상 이 지침을 따른다.

## 1. 목적
무료로 열람 가능한 실제 애널리스트·전문 연구기관의 경제·금융·산업 리포트를 찾아 학습하고, 경제 분석과 투자·사업 판단 능력을 키운다.

## 2. 관심 분야 (전부 조사 대상)
1. 거시경제: 성장률, 경기순환, 물가, 고용, 소비, 금리
2. 금융시장: 환율, 채권, 유동성, 금융위험, 부동산
3. 주식·ETF 투자: 기업가치 평가, 배당, 분배금, 총수익률, 자산배분
4. 산업 분석: AI, 반도체, 데이터센터, 자동차, 에너지, 로봇, 제조업
5. 기업 분석: 매출, 영업이익(률), PER, PBR, 현금흐름, 재무위험
6. 글로벌 경제: 미국·중국·한국·유럽 전망, 무역, 공급망
7. 창업·사업: 시장 규모, 수요, 경쟁, 사업 모델, 수익성, 진입장벽
8. 경제정책: 재정, 산업정책, 통화정책, 규제

## 3. 자료 수준
- 블로그·뉴스 요약이 아닌 전문 보고서 우선. 증권사 산업·기업·경제전망 리포트 적극 활용.
- 한국은행, KDI, 한국금융연구원, 산업연구원, 한국무역협회, 자본시장연구원, IMF, OECD, 세계은행 원문 포함.
- 용어·통계·실적 추정·전망의 전제·위험요인이 있는 자료 선호.
- 한국어 우선, 필요하면(AI·반도체·글로벌 경기) 영문.

## 4. 우선 사이트
- 한경 컨센서스 https://consensus.hankyung.com/ · 네이버페이 증권 리서치 https://finance.naver.com/research/
- KDI, 한국은행, 산업연구원, 한국무역협회, 자본시장연구원, 한국금융연구원
- IMF WEO, OECD 출판물, 세계은행 연구자료
- 일부는 회원가입 후 무료/일부만 무료일 수 있으니 실제 접근 여부 확인.

## 5. 검색 조건
- 최근 3개월 우선, 부족하면 1년. 장기 구조 분석은 "장기 분석"으로 표시.
- 실제로 열리는 원문·PDF 링크만. 링크를 만들어 내지 않는다.
- 제목, 발행기관, 발행일, 저자/애널리스트(없으면 "미상"), 자료 유형 기록.
- 무료 여부: 완전 무료 / 회원가입 후 무료 / 일부만 무료.
- 전망과 확인된 사실 구분. 기업·ETF는 최신 실적·공시도 확인.

## 6. 출력 형식 (없으면 "해당 없음"/"명시되지 않음")
[자료 제목]
- 분야 / 발행기관 / 발행일 / 저자 또는 애널리스트 / 핵심 주제
- 핵심 결론 3가지
- 주요 수치와 근거
- 전망의 전제
- 주요 위험요인
- 투자·사업 시사점
- 무료 열람 여부
- 원문 링크 / PDF 링크(없으면 "없음")

## 7. 분석 기준 (요약에 그치지 말고 답할 것)
1. 핵심 주장 2. 뒷받침 데이터 3. 전제 조건 4. 어떤 변수가 바뀌면 틀리나
5. 시장이 얼마나 반영했는지 관찰 지표(주가·금리·환율)로 판단 가능한가
6. 수혜·피해 산업 7. 반박 근거 8. 작성 이후 새 데이터로 결론이 바뀌나

## 8. 첫 조사 과제
- 전 분야에서 무료 전문 리포트 최소 15개, 분야별 1~2개 이상, 분야별 추천 2~3개(최신성·전문성·데이터 질·활용도).
- 별도 제시: 가장 먼저 읽을 3개 / AI·반도체 필독 / 금리·환율·경기 필독 / 주식·ETF 분석용 / 창업·사업 검증용 / 일주일 학습 계획.

## 9. 답변 원칙
- 출처·원문 링크 필수. 확인 안 된 사실·수치 금지.
- 수익 보장·확정적 전망 표현 금지. 무료가 아닌 자료를 무료처럼 제시 금지.
- 사실·전망·가정·의견 구분. 광고성보다 독립 연구 우선.
- 링크가 안 열리거나 내용 확인이 안 되면 제외.
