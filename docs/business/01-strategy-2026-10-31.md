## 0. 결론 먼저

1. **지금은 돈을 받으면 안 된다.** 기능은 많지만, (a) 쓰는 데이터 대부분이 "개인·비상업 용도" 성격이고 상업 이용 허락이 없으며, (b) 유료로 투자 정보를 주면 한국 법상 **유사투자자문업 신고** 문제가 걸리고, (c) GitHub Pages 자체가 상업 SaaS 호스팅을 금지한다. 셋 다 "기능을 더 만들어서" 풀리는 문제가 아니다.
2. **가장 큰 문제는 기능이 아니라 "사용자 0명"이다.** 지금 이 앱은 만든 사람 한 명을 위해 맞춰진 개인 도구다(관심종목·핫 뉴스 읽음 등이 전부 폰 브라우저 localStorage). 누가 쓰는지, 다시 오는지 잴 수단도 없다.
3. **"왜 돈을 내야 하나?"에 지금은 명확히 답할 수 없다.** → 원칙대로 **유료 기능 개발 보류.** 대신 90일 동안 "무료로 써 줄 사람이 있는가"부터 검증한다.
4. 가장 현실적인 첫 수익 경로는 **구독이 아니라 ① 콘텐츠(숏폼·블로그)로 사람을 모으고 ② 광고/후원 같은 '투자조언 대가가 아닌' 수입**이다. 단 이것도 데이터 약관 정리(공식·허용된 출처로 교체 또는 개인용 유지) 뒤에.

### A-4. 기능 목록과 3분류

**이미 충분히 구현된 것 [확인]**
- 국장·미장 차트(일·주·월·년봉, 이동평균 설정, 고점·저점 대비, 비교 차트), 전 종목 검색(너그러운 검색), 관심종목
- 오늘의 리포트(5팀 파이프라인, 국장·미장 하루 1번) + 주간 리포트
- 경기 국면 판정(7개 지표), 업종 16개 흐름, 정부 정책 정리(손으로), 경제 일정 달력, 큰 발표, 급락 점검
- 장중 사건 뉴스 + 핫 뉴스 묶기, 공시 알림, 증권사 무료 리포트 목록, 투자 공부(용어집·움직인 이유)

- 자동 작업 고장 감시(실패 알림, 데이터 30% 이상 비면 그날 자료 안 만듦, 화면에 "자료가 N일 거예요" 경고)

**개선이 필요한 것**
- 데이터 검증: 고장 감시는 "비었는지·늦었는지"만 본다. **값이 틀린지**(액면분할 누락, 단위 오류, 이상 급등락)는 일부만 점검 **[확인: health.check_data는 결측·지연 위주, 급등락 일부]**
- 출처·시각 표시: 홈 하단 전체 갱신 시각과 일부 칸(지수·뉴스·정책)에는 있음. **칸·숫자마다 출처**는 없음.
- 수정주가 일관성: 스크립트마다 `auto_adjust=True/False`가 섞여 있음(daily·all_stocks는 False, macro·lab·industry_map은 True). 같은 종목이 화면마다 다른 기준일 수 있음 **[확인: 코드], 실제 숫자 차이 [확인 필요]**
- 재무: Yahoo `info`는 비공식이고 국장 재무는 누락·지연이 잦다는 평이 많음 **[추정]**. DART 정식 재무 API 미사용.
- 개인화가 한 폰에만 묶임(기기 바꾸면 사라짐), 텔레그램은 1명 전용.

**아직 구현되지 않은 것 [확인: 코드에 없음]**

- 실시간 시세(증권사 API 필요, 계좌 없음으로 보류)
- 여러 사용자에게 알림 보내기

데이터 정확성 항목별 현황 [확인: 코드]
- 실시간/지연: 종가 기준, 실시간 아님(화면에 표시함).
- 수정주가·배당: Yahoo `Close`(분할 반영, 배당 미반영)와 `Adj Close`/`auto_adjust=True`(배당 반영)를 스크립트마다 다르게 씀. returns.py는 둘 다 받아 주가 상승과 배당을 나눠 계산 — 설계는 맞음.
- 액면분할·병합: Yahoo 반영에 의존, 별도 검증 없음. 국장 분할 반영 지연 사례 여부 [확인 필요].
- 환율: Yahoo `KRW=X` 종가 하나.
- 재무 기준일: Yahoo `info` 기준일 표시 없음 [확인 필요].
- 오류가 정상처럼 보이는 문제: 시세가 비면 그날 자료 생략·"N일 전 자료" 경고는 있음. 그러나 **잘못된 값(예: 단위 오류, 분할 미반영으로 -50% 폭락처럼 보이는 것)** 을 걸러 경고하는 장치는 약함.
- API 제한: Yahoo 비공식이라 차단·429·응답 형식 변경 시 전체가 멈춤(과거 이 환경에서 429 겪음, 메모 기록).

## E. 향후 90일 실행 로드맵 (2026-11-01 ~ 2027-01-29)

비용은 전부 0원 목표. 예외만 표시.

### Phase 1 — 신뢰성 확보 (1~4주)
- 목표: "틀린 숫자를 정상처럼 보여 주지 않는다" + 출처 정리
- 작업: ① 데이터 출처 약관 원문 확인표 완성(D1) ② 이상값 검사 추가(하루 ±30% 넘는 대형주, 분할 의심, 0·음수 가격 → 해당 칸 "확인 중" 표시) ③ 칸마다 출처·기준 시각 작은 글씨 ④ 수정주가 기준 통일 ⑤ 적립식 계산기 계산식을 외부 계산기 3종과 대조(대표 ETF 5개)
- 비용 0원 / 난이도 중
- 완료 기준: 대조 결과 차이 ±0.5%p 안, 이상값 테스트 통과, 출처표 문서화
- 실패 위험: Yahoo 상업 이용 불가가 확정되면 대체 출처가 마땅치 않음(국장은 공공데이터포털 시세 API 검토 [확인 필요])
- 다음 단계 조건: D1·D4·D7 해결 또는 "개인·비상업 유지" 결정

### Phase 2 — 사용자 가치 검증 (5~10주)
- 목표: 우선 고객(장기 적립식·배당) 무료 사용자 확보와 반응 측정
- 작업: ① 쿠키 없는 무료 방문 측정(예: GoatCounter 무료 플랜 — 조건 [확인 필요]) ② 피드백 버튼(구글 폼) ③ "내 적립식 계획 폭락 테스트" 숏폼 6~10편(사용자의 숏폼 목표와 연결) ④ 초대한 5~10명 사용 관찰
- 비용 0원 / 난이도 낮음
- 완료 기준(예시 목표, 근거 없는 수치 아님 — 검증용 문턱): 주간 방문자 100명, 2주 안 재방문 20% 이상, 피드백 10건, "돈 내고 쓰겠다" 응답 3건 이상
- 실패 위험: 유입이 안 됨, 계산기만 한 번 쓰고 안 옴
- 다음 단계 조건: 위 문턱 중 재방문·피드백 충족

### Phase 3 — 초기 수익화 (11~13주, 조건부)
- 목표: 법적 위험 낮은 수익 1개 시험
- 작업: ① 금감원·변호사 무료 상담(대한법률구조공단 등)으로 유사투자자문 해당 여부 확인 ② 광고/후원 시험(데이터 약관상 허용 범위에서) ③ 유료 구독은 **설계 문서만**: 무료=리포트·차트, 유료 후보=개인 포트폴리오 폭락 시뮬레이션 저장·알림
- 비용: 사업자등록 0원, 도메인 연 1~2만 원
- 완료 기준: 법률 확인서/상담 기록, 첫 수익 1원이라도 발생
- 실패 위험: 법적 결론이 "신고 필요" → 신고 비용·교육 부담

### Phase 4 — 성장·확장 (90일 이후)
- 사용자 확보: 숏폼 → 계산기 링크 / 재방문: 주간 리포트 이메일·텔레그램 채널 / 유료 전환: Phase 2 데이터가 있을 때만 / 자동화: 지금 수준 유지 / 확장: 공식 데이터 계약은 매출이 비용을 넘을 때만.

## F. 지금 가장 먼저 할 일 TOP 5

1. **데이터 약관 원문 확인표 만들기** (Yahoo·구글 뉴스·네이버·KRX·DART·ECOS·faireconomy) — 이게 "수익화 가능한가"의 1번 관문.
2. **이상값 검사 + "확인 중" 표시** — 틀린 숫자 노출 방지.
3. **방문 측정 + 피드백 버튼** — 무료, 하루 작업. 이게 없으면 Phase 2 자체가 불가능.
4. **핵심 하나로 첫 화면 정리 실험**: "내 적립식·배당 계획 폭락 테스트"를 신규 방문자 첫 화면으로 (지금 홈은 시세 앱처럼 보임).
5. **숏폼 3편으로 수요 테스트**: "S&P500 매달 50만 원, 2008년에 시작했다면?" 같이 계산기 결과를 영상화 → 링크 클릭 수로 수요 측정.

## 마지막 질문 5개

1. **돈을 받을 수 있는 수준인가?** → **아니다.** 기능 완성도는 개인 도구로 높은 편이지만, 데이터 권리·투자자문 법규·호스팅 약관·사용자 검증 네 가지가 비어 있다.
2. **가장 큰 문제?** → **아무도 안 써 봤다는 것(가치 미검증)**, 그리고 그 다음이 **데이터 상업 이용 권리**. 기능 부족은 문제가 아니다.
3. **소자본 1인 개발자에게 가장 현실적인 모델?** → **콘텐츠(숏폼·블로그)로 모으고, 무료 도구 + 광고/후원.** 구독은 투자자문 규제·결제·서버 비용이 한꺼번에 와서 마지막 순서.
4. **지금 개발할 것 / 하면 안 되는 것**
   - 할 것: 이상값 검사·출처 표시, 방문 측정·피드백, 신규 방문자용 첫 화면(폭락 테스트)
   - 하면 안 되는 것: 결제·구독·로그인, 매매 신호·종목 추천(규제), 실시간 시세 흉내, AI 요약 기능 추가(복제 쉬움), 기능 수 늘리기
5. **가장 먼저 검증할 가설** → **"장기 적립식·배당 투자자는 '내 계획이 폭락을 버틸 수 있나'를 보여 주는 도구에 두 번 이상 다시 온다."** 재방문이 안 나오면 유료는 의미 없다.
