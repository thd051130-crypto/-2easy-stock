# 02 서비스 기획

- 상태: 뼈대 (2026-10-31)
- 이 문서의 목적: **누구에게 어떤 가치를** 주고, 남과 무엇이 다르며, 어떤 원칙으로 운영·수익화할지 정해요.
- 책임 범위: 사용자 특성·요구, 제공 가치, 차별점, 경쟁 조사 항목, 수익화 방향, 운영 원칙.
- 다루지 않는 것: 범위·제외 → [01](01-project-overview.md), 화면 흐름 → [03](03-user-experience.md), 데이터 비용·라이선스 → [07](07-data-providers.md), 운영 절차 → [09](09-operations-security.md)

## 핵심 질문

1. 핵심 사용자가 지금 겪는 불편은 무엇이고, 기존 서비스(네이버페이 증권·토스증권·증권사 MTS 등)로 안 풀리는 건 무엇인가?
2. 시세 앱과 경쟁하지 않고 이길 수 있는 지점은 어디인가?
3. 정보 제공 서비스로서 법적으로 안전한 수익 방식은?

## 목차

### 1. 사용자 특성
- 쓸 내용: 경험 수준, 국장/미장 비중, 주로 보는 정보, 사용 기기(모바일 우선 [가설])
- 지금 아는 것: 01 수익화 진단 B장의 고객군 7개 (지불 가능성은 [가설])
- 필요한 결정: 우선 고객군 하나 — 01 수익화 진단은 장기 적립식·배당 투자자를 추천 [가설]

### 2. 사용자 요구
- 쓸 내용: 요구 → 영역 매핑 (예: "이 회사 돈 잘 버나?" → 재무, "배당 언제 얼마?" → 배당)
- 검증 방법: 인터뷰·피드백 질문 목록 (09 측정과 연결)

### 3. 제공 가치
- 쓸 내용: 영역별 "쉬운 요약 + 깊은 상세 + 출처" 약속을 문장으로

### 4. 서비스 차별점
- 쓸 내용: 차별점 후보와 근거 수준
- 지금 아는 것 [가설]: 시세·속도로는 이길 수 없음(01 수익화 진단 A-6). 후보 = 원 공시 기반 재무를 **쉬운 한국어 + 계산 근거 공개**로, 국내외를 같은 틀로, 출처·기준일 투명성
- 필요한 결정: 차별점 1개 확정

### 5. 경쟁 서비스 조사 항목
- 조사할 것: 무료 범위, 재무 깊이, 배당 정보(날짜 구분), 출처 표시 방식, 초보자 설명, 모바일 사용성, 광고 여부
- 대상 후보: 네이버페이 증권, 토스증권, 증권사 MTS, 인베스팅닷컴, 아이투자, (미국) 해외 무료 사이트 — 각 무료 범위는 **확인 필요**

### 6. 수익화 방향
- 지금 아는 것: 01 수익화 진단 결론 "지금은 유료화 보류", 추천 순서 콘텐츠+광고/후원 → 계산기·교육 → (조건부) 구독
- 이 문서에서 정할 것: V2 설계에 미리 넣어 둘 것(예: 광고 자리 없음/있음)과 넣지 않을 것(결제·로그인)
- 필요한 결정: [미결정 Q-15], 법률 확인 [Q-20]

### 7. 운영 원칙
- [결정 D-02] 추천 없음, [D-07] 권한 확인된 데이터만, [D-08] 출처·기준일 표시
- 쓸 내용: 문구 원칙(“사세요/파세요/유망” 금지 단어 목록), 오류 정정 공지 원칙, 데이터 지연 안내 원칙
