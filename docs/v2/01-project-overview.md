# 01 프로젝트 개요

- 상태: 뼈대 (2026-10-31)
- 이 문서의 목적: V2가 **왜, 무엇을, 어디까지** 하는지 한 장으로 정해요. 다른 모든 문서는 여기 범위를 넘지 않아요.
- 책임 범위: 배경·정의·대상·목표·가치·범위·제외 범위·성공 기준.
- 다루지 않는 것: 사용자 조사·경쟁·수익화 → [02](02-service-planning.md), 화면 → [03](03-user-experience.md)·[04](04-information-architecture.md), 데이터 공급 가능 여부 → [07](07-data-providers.md)

## 핵심 질문

1. V2는 V1을 고치는 것이 아니라 무엇으로 **다시 정의**하나?
2. 초기 버전에서 꼭 들어가는 것과 절대 안 들어가는 것은?
3. "성공했다"는 무엇으로 재나?

## 목차

### 1. 프로젝트 배경
- 쓸 내용: V1(개인 도구, 리포트·신호 중심, Yahoo 의존)에서 V2(정보 플랫폼)로 바꾸는 이유
- 지금 아는 것 [사실]: V1은 시세·재무·배당 거의 전부가 Yahoo, 원본이 공개 저장소·사이트로 나감 ([기초 분석서](01-architecture-design.md) 1·2장, [02 진단](../business/02-data-provider-audit-2026-10-31.md) 0장). 수익화 전 막는 것 4가지 (01 수익화 진단 D)
- 필요한 결정: 없음

### 2. 서비스 정의
- 쓸 내용: "개인 투자자를 위한 금융·기업 정보 플랫폼" 한 문장 정의와 하지 않는 것
- 지금 아는 것: [결정 D-02] 정보 제공, 추천·신호 없음

### 3. 핵심 사용자
- 쓸 내용: 일반 투자자 ~ 적극적 개인 투자자 사이. 상세 특성은 02로
- 지금 아는 것: 주식 경험 있음, 기본 용어는 앎, 전문 분석은 어려움, 실적·주가·배당·경제를 직접 확인하고 싶음 (사용자 요청문)

### 4. 서비스 목표
- 쓸 내용: 초기 버전 목표 3개 이내 (예: ① 국내외 기업의 재무·배당을 출처와 함께 쉽게 ② 라이선스 문제 없는 데이터만 ③ 하나의 검색으로 진입)
- 필요한 결정: 목표 우선순위 [미결정 Q-14]

### 5. 핵심 가치
- 정확한 금융정보 / 쉬운 설명 / 깊이 있는 상세 / 명확한 출처 / 국내외 한곳에서 (사용자 요청문)
- 쓸 내용: 가치마다 "화면에서 어떻게 보이는지" 한 줄 (예: 출처 → 모든 숫자 칸 아래 `출처 · 기준일`)

### 6. 개발 범위
- [결정 D-04] 5개 영역: 통합 검색, 주가, 기업 정보·재무제표, 배당, 경제 정보
- 쓸 내용: 영역별로 **국장·미장 각각 초기 제공 가능 여부** — 판단은 07, 여기엔 결과 표만
- 지금 아는 것 [기초 분석서 10장]: 월 5만 원으로 미장 주가 공개 표시 확인된 방법 없음
- 필요한 결정: 공시 포함 [Q-08], 뉴스 포함 [Q-09], 지원 종목 범위 [Q-17]

### 7. 제외 범위
- [결정 D-03] 자동매매, 매수·매도 추천, AI 주가 예측, 복잡한 포트폴리오 관리, 불필요한 커뮤니티·소셜
- [결정 D-05] 실시간 시세 (초기)
- 쓸 내용: V1 기능 중 V2에 안 가져가는 것 목록 (근거: [기초 분석서](01-architecture-design.md) 3-3절)
- 필요한 결정: V1 적립식 계산기·폭락 대비 [Q-10]

### 8. 성공 기준
- 쓸 내용: 출시 전 기준(데이터 품질)과 출시 후 기준(사용자 행동)을 나눠서
- 초안 [제안]: 출시 전 — 공개 데이터 `license_status` 미확인 0건, 표본 재무 원 공시 일치, 모든 숫자에 출처·기준일. 출시 후 — 재방문, 검색→기업 페이지 이동률 (수치는 [Q-14])
- 측정 방법은 09로
