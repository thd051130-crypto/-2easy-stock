## 1. 프로젝트 배경

V1은 한 사람을 위한 개인 도구로 자랐어요. 리포트·신호·실험실 중심이고, 데이터 대부분이 Yahoo(yfinance)예요 [사실: [기초 분석서](01-architecture-design.md) 2-5절]. 그 원본이 공개 저장소와 사이트로 그대로 나가고 있어요 [사실: [03 검토](../business/03-data-migration-risk-review-2026-10-31.md) 1장].

이 구조로는 여러 사람이 쓰는 서비스가 될 수 없어요. 막는 것은 네 가지예요 [01 수익화 진단 D장]:
1. 데이터의 상업 이용 권리가 없음
2. 추천처럼 읽히는 리포트 (유사투자자문 소지)
3. GitHub Pages의 상업 이용 금지
4. 사용자 검증이 0

그래서 V2는 V1을 고치는 일이 아니에요. **서비스의 방향과 구조를 다시 정하는 프로젝트**예요 [결정 D-02].

## 2. 서비스 정의

> 이지스톡 V2는 일반 투자자와 적극적인 개인 투자자 사이의 사용자를 위한 **금융정보 플랫폼**이에요. 기업·주가·재무제표·배당·경제지표 정보를 한곳에서 보여 줘요. 전문적인 데이터도 다루지만 쉽게 설명해요. **투자 판단을 대신하지 않고, 판단에 필요한 정보를 줘요.** [결정 D-13]

하는 것 / 하지 않는 것

| 하는 것 | 하지 않는 것 |
|---|---|
| 원천 데이터를 정리해 보여 주기 | 무엇을 살지·팔지 말하기 |
| 숫자의 뜻과 계산 기준 설명 | 좋다·나쁘다 등급 매기기 ([미결정 Q-13]) |
| 과거 추이 보여 주기 | 미래 주가 예측 |
| 출처·기준일·갱신 시각 표시 | 출처 없는 숫자 보여 주기 |

## 3. 비전 및 목표

- **비전** [제안]: "회사와 시장을 스스로 이해하고 싶은 개인 투자자가 가장 먼저 여는 정보 화면."
- **초기 버전 목표** [제안, 우선순위는 [미결정 Q-14]]
  1. 국내외 상장 기업의 **재무·배당을 원천 데이터와 일치하게**, 출처와 함께 보여 준다.
  2. **라이선스가 확인된 데이터만** 공개한다 [결정 D-07].
  3. 검색 한 번으로 기업 정보에 닿고, 초보자도 핵심 수치를 이해할 수 있다.
- 목표가 아닌 것: 실시간성, 기능 수, V1 기능 전부 옮기기.

## 4. 핵심 사용자

일반 투자자와 적극적인 개인 투자자 사이 [결정 D-13]:
- 주식 투자를 시작했거나 어느 정도 해 본 사람
- 기본 용어는 알지만 전문 분석은 어려운 사람
- 실적·주가·배당·경제 상황을 직접 확인하고 싶은 사람

페르소나·불편·시나리오는 [02](02-service-planning.md) 1~3장에 있어요.

## 5. 핵심 가치

설계 판단이 갈릴 때는 이 다섯 가지로 정해요 [결정 D-14]. 화면에서 지켜야 할 최소 기준을 같이 적었어요 [제안].

| # | 가치 | 뜻 | 최소 기준 | 상세 문서 |
|---|---|---|---|---|
| 1 | 정확성 | 원천 데이터와 일치 | 표본 대조로 원 공시·원 통계와 일치, 이상값은 "확인 중" 표시 | [05](05-data-architecture.md) 5장 |
| 2 | 투명성 | 출처·기준일·갱신 시각 | 모든 숫자에 `출처 · 기준일`, 상세 보기에 갱신 시각 | [05](05-data-architecture.md) 8장 |
| 3 | 이해도 | 금융지표를 쉽게 설명 | 지표마다 쉬운 설명. 용어는 없애지 않고 설명 [결정 D-15] | [03](03-user-experience.md) 5장 |
| 4 | 깊이 | 상세 재무와 과거 추이 | 연간·분기 재무제표, 여러 해 추이, 계산 기준 공개 | [08](08-feature-specification.md) |
| 5 | 편의성 | 흩어진 정보를 한곳에 | 기업 하나에서 주가·재무·배당을 이동 없이 | [04](04-information-architecture.md) |

가치가 서로 부딪치면 **정확성·투명성이 먼저**예요 [제안]. 예를 들어 데이터를 확인할 수 없으면 편의성을 포기하고 칸을 비워요.

## 6. 제공 범위

핵심 영역 [결정 D-16]: 통합 검색 · 국내외 주가 · 기업 기본정보 · 기업 재무제표 · 재무지표 · 배당 · 국내외 경제지표

초기 제공 가능성은 데이터 라이선스에 달려 있어요. 아래는 **실현 가능성** 판단이에요. 근거는 [07](07-data-providers.md)과 [기초 분석서](01-architecture-design.md) 10장이에요.

| 영역 | 국장 | 미장 | 막는 것 |
|---|---|---|---|
| 통합 검색 | 가능 | 가능 (ETF 목록은 확인 필요) | 목록 원천 약관 확인 |
| 주가 (일봉) | 조건부 (공공 시세, 하루 늦음) | **현재 불가** (공개 표시가 확인된 공급자 없음) | [Q-05], [Q-06], [Q-07] |
| 기업 기본정보 | 가능 | 가능 | 약관 확인 |
| 재무제표 | 가능 (DART) | 가능 (EDGAR) | 약관 확인 |
| 재무지표 | 가능 | **주가가 필요한 지표(PER·PBR·배당수익률)는 미장 주가에 묶임** | [Q-06] |
| 배당 | 조건부 (배당락일 원천 확인 필요) | 조건부 | 확인 필요 |
| 경제지표 | 가능 (ECOS) | 조건부 (FRED 시리즈별) | 시리즈별 확인 |
| 공시 | 별도 검토 | 별도 검토 | [미결정 Q-08] |
| 뉴스 | 별도 검토 | 별도 검토 | [미결정 Q-09] |

- 지원 종목 범위 (전 종목 / 대형주부터): [미결정 Q-17]
- 주가는 일봉 중심이고 실시간은 제외해요 [결정 D-05].

## 7. 제외 범위

초기 버전에서 만들지 않는 것 [결정 D-03, D-17]:

| 제외 | 이유 |
|---|---|
| 자동매매 | 정보 서비스 범위 밖, 법적 위험 |
| 종목 추천 | 판단을 대신함 (D-02), 유사투자자문 소지 |
| 매수·매도 신호 | 위와 같음 |
| AI 주가 예측 | 정확성 원칙과 충돌 |
| 복잡한 포트폴리오 관리 | 핵심 영역 밖 |
| 커뮤니티 | 운영·법적 부담, 핵심 영역 밖 |
| 소셜 기능 | 위와 같음 |
| 실시간 시세 | 비용·라이선스 (D-05) |
| 로그인·결제 | 유료 기능은 수요를 확인한 뒤에 (D-18) |

V1 기능 중 가져가지 않는 것은 [기초 분석서](01-architecture-design.md) 3-3절 목록이에요. V1의 적립식 계산기·폭락 대비를 넣을지는 [미결정 Q-10]이에요.

## 8. 성공 기준

**출시 전 (품질) 기준 — 모두 만족해야 공개해요** [제안]

| 기준 | 측정 |
|---|---|
| 공개 데이터 중 라이선스 미확인 0건 | 공개 빌드 검사 |
| 모든 숫자 칸에 출처·기준일 | 화면 점검 |
| 재무 표본 일치 | 국장·미장 대형주 표본(개수는 Q-14)이 원 공시와 일치 |
| 수집 실패 시 지난 정상본 + 경고 표시 | 실패 상황 시험 |
| 핵심 영역 화면 사용자 검수 통과 | 캡처 검수 (D-12) |

**출시 후 (가치 검증) 기준 — 수치는 미결정** [미결정 Q-14]

| 기준 | 왜 | 측정 수단 |
|---|---|---|
| 재방문 | 다시 쓸 만한 정보인지 | 방문 측정 도구 ([09](09-operations-security.md), 도구는 미정) |
| 검색 → 기업 상세 이동 | 검색이 제 역할을 하는지 | 같음 |
| 상세 보기 열람 | "깊이"에 수요가 있는지 | 같음 |
| 오류 신고와 정정 시간 | 정확성 | 피드백 창구 |

> 01 수익화 진단은 검증용 문턱의 예로 "주간 방문자 100명, 2주 재방문 20%"를 들었어요. 근거가 있는 수치는 아니라서 **확정하지 않아요**.
