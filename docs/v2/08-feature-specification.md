# 08 기능 명세

- 상태: 뼈대 (2026-10-31)
- 이 문서의 목적: 기능마다 **입력·출력·처리·예외**를 개발할 수 있는 수준으로 정해요.
- 책임 범위: 기능 단위 명세, 기능별 데이터 요구(05 엔터티 이름으로), 예외 처리와 화면 문구.
- 다루지 않는 것: 페이지 배치 → [04](04-information-architecture.md), 데이터 정의 → [05](05-data-architecture.md), 공급 가능 여부 → [07](07-data-providers.md)

## 핵심 질문

1. 각 기능은 어떤 입력을 받아 어떤 결과를 보여 주나?
2. 데이터가 없거나, 늦거나, 이상할 때 기능은 어떻게 동작하나?
3. 어떤 기능이 V1 코드를 재사용하나? ([기초 분석서](01-architecture-design.md) 3장)

## 0. MVP 범위 분류 [제안, 확정은 Q-25]

원칙: 적은 기능이라도 정확하게 [결정 D-21의 취지, 사용자 2026-10-31]. 근거는 [11](11-monetization-and-community.md) 3장, 권한은 [07](07-data-providers.md).

| 기능 | 국장 | 미장 | 이유 |
|---|---|---|---|
| 통합 검색 (종목·기업) | **MVP 필수** | **MVP 필수** | 모든 흐름의 입구. 목록 원천 약관만 확인 |
| 기업 기본정보 | **MVP 필수** | **MVP 필수** | DART·EDGAR |
| 재무제표 (연·분기, 원문 링크) | **MVP 필수** | **MVP 필수** | 공공 원천, 정확성 검증 가능 |
| 재무지표 — 주가 불필요 (ROE·부채비율·영업이익률·EPS) | **MVP 필수** | **MVP 필수** | 재무만으로 계산 |

| 배당 — 배당수익률·날짜 4종 | 데이터 권한 확보 후 | 데이터 권한 확보 후 | 주가·배당락일 원천 필요 |
| 공시 목록·원문 링크 | **MVP 필수** (기업 페이지 안 링크) | **MVP 필수** | 정확성(원문 확인). 공시 피드·알림은 이후 [Q-08] |
| 경제지표 (ECOS 금리·환율 등 3~5개) | MVP 이후 추가 (1순위) | MVP 이후 추가 (FRED 공공 시리즈) | 쉽지만 MVP를 작게 유지 |
| 주가 일봉 차트 | 데이터 권한 확보 후 (확인되면 MVP 후보) | 데이터 권한 확보 후 | [Q-05], [Q-06] |

| 관심종목 (기기 저장) | MVP 이후 추가 | MVP 이후 추가 | 로그인 없이 가능 |
| 알림·기기 간 동기화 | 초기에는 제외 | 초기에는 제외 | 로그인·서버 필요 |
| 뉴스 | 초기에는 제외 | 초기에는 제외 | 권한 원천 없음 [Q-09] |
| 커뮤니티 | 초기에는 제외 (장기 후보) | 같음 | [11](11-monetization-and-community.md) 1장, [P-01] |
| 피드백·오류 신고 창구 | **MVP 필수** | 같음 | 정확성 유지와 사용자 목소리 |

## 기능 명세 틀 (모든 기능 공통)

| 칸 | 쓸 내용 |
|---|---|
| 목적 | 사용자가 얻는 것 한 줄 |
| 입력 | 사용자 입력(검색어, 기간 등) + 필요한 데이터 엔터티 |
| 처리 | 계산·정렬·필터 (계산식 이름) |
| 출력 | 화면에 보이는 값과 형식, 출처·기준일 |
| 예외 | 데이터 없음 / 지연(`stale`) / 확인 중(`check`) / 일부만(`partial`) / 라이선스 없음 |
| 재사용 | V1 파일·함수 (있으면) |
| 시장 | 국장 / 미장 제공 여부 |
| 결정 필요 | decision-log 번호 |

## 목차

### 1. 통합 검색
- 재사용: V1 `symbols.py` 검색 함수, `site/app.js` JS 검색 (초성·오타·별명)
- 쓸 내용: 검색 대상(종목·ETF·경제지표), 정렬 규칙, 결과 없음·동명·상장폐지

### 2. 주가 정보
- 쓸 내용: 종가 요약, 기간 차트, 이동평균, 52주 범위, 수익률(원가격/수정 기준 표시), 거래량
- 예외: 미장 주가 없음 [Q-06], 국장 하루 늦음 [Q-05]
- 재사용: V1 SVG 차트, `marketdata.py` 계산 함수

### 3. 기업 기본정보
- 쓸 내용: 이름·업종·결산월·회계기준·상장 시장·식별자, 업종 매핑(KRX·SIC)

### 4. 재무제표
- 쓸 내용: 손익·재무상태·현금흐름, 연/분기, 연결/별도, 4분기 계산, 정정 반영, 원 공시 링크
- 예외: 매핑 안 된 계정 → 빈칸 + 이유 (추정해 채우지 않음)

### 5. 재무지표
- 쓸 내용: PER·PBR·ROE·부채비율·영업이익률 등 계산식, 입력 레코드 표시("계산식 보기"), 통화 불일치 처리
- 결정 필요: 재무 등급 [Q-13]. 미장 PER은 주가 없으면 표시 안 함

### 6. 배당 정보
- 쓸 내용: 1주당 배당, 배당수익률(기준 명시), 배당성향, 이벤트 날짜 4종
- 재사용: V1 `returns.py` 계산 (배당 이벤트 입력으로 바꿔서)
- 예외: 배당락일 없음 → 회계연도 기준 표시

### 7. 경제 정보
- 쓸 내용: 지표 카드(값·기준일·전기 대비), 장기 차트, 발표 일정, 시리즈 설명
- 재사용: V1 `world.py` ECOS, `macro.py` FRED 수집
- 하지 않을 것: '경기 국면 판정' 같은 해석 문장 [제안]

### 8. 공시 및 뉴스 (초기 포함 여부 검토)
- 공시: 목록·제목·접수일·원문 링크 (원문 복제 안 함). 재사용: V1 `disclosures.py`. 포함 여부 [Q-08] — 추천 포함
- 뉴스: 라이선스 확인된 원천 없음 → 추천 제외 [Q-09]
