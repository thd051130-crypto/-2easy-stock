# 이지스톡 V2

V2 개발은 `develop-v2` 브랜치에서 해요. `main`은 V1 보존용이라 건드리지 않아요.

## 브랜치 규칙

| 브랜치 | 용도 |
|---|---|
| `main` | V1 그대로 보존 (지금 사이트가 여기서 나감) |
| `develop-v2` | V2 개발 기준 브랜치 |
| `v2/<작업이름>` | V2 작업 하나씩. `develop-v2`에서 따고, PR도 `develop-v2`로 |

Claude·ChatGPT 둘 다 V2 작업은 **`develop-v2`를 기준(base) 브랜치**로 써요. `main`으로 PR을 보내지 않아요.

## V2 목표

1. **라이선스 문제 없는 데이터 공급자로 교체.** 지금은 시세·재무·배당·환율·지수가 거의 다 Yahoo(yfinance)이고, 원본이 공개 저장소·사이트로 그대로 나가요. 공공 API(DART·EDGAR·ECOS·FRED·금융위 주식시세)를 중심으로 바꾸고, 재배포가 확인 안 된 미장 주가 등은 줄이거나 끄기.
2. **Adapter 구조.** 화면과 분석 코드가 공급자를 직접 부르지 않게, 공급자마다 Adapter 한 겹을 두고 지금 JSON 모양은 그대로 유지. 공급자를 바꿔도 Adapter만 바꾸면 되게.
3. **데이터 메타 붙이기.** 데이터마다 출처(source)·수정주가 여부(adjustment)·라이선스 상태(license_status)·데이터 상태(data_status)를 남기기.
