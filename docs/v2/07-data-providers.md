# 07 데이터 공급자

- 상태: 뼈대 + 초안 연결 (2026-10-31)
- 이 문서의 목적: 데이터 영역마다 **어떤 공급자를 쓸 수 있는지, 얼마인지, 무엇이 허락되는지** 정해요. **V2에서 라이선스를 상세히 다루는 유일한 문서**예요. 05·06·09는 여기를 가리켜요.
- 책임 범위: 공급자별 제공 데이터·원본 형식 요약·비용·권한 7항목·확인 상태·교체 전략, 약관 확인 기록 위치.
- 다루지 않는 것: 공통 스키마·변환 → [05](05-data-architecture.md), Adapter 코드 → [06](06-system-architecture.md)
- 초안: [02 진단](../business/02-data-provider-audit-2026-10-31.md) 2~4·7~8장, [03 검토](../business/03-data-migration-risk-review-2026-10-31.md) 3장, [기초 분석서](01-architecture-design.md) 8·10장.

## 원칙

- [결정 D-07] 상업적 이용·웹 표시 권한이 확인된 데이터만. **무료 = 상업 허용이 아님.**
- 공식 약관 원문이나 서면 확인이 없으면 **"확인 필요"**. 확인 기록은 `v2/licenses/<공급자>.md`(원문 날짜·캡처 경로·결론) [제안].
- [결정 D-06] 데이터 예산 월 5만 원 우선 목표.

## 핵심 질문

1. 영역 × 시장마다 월 5만 원 안에서 합법적으로 공개 표시할 수 있는 공급자가 있나?
2. 없으면 무엇을 비워 두고, 무엇을 견적 받나?
3. 공급자를 바꿀 때 무엇이 깨지나?

## 권한 확인 7항목 (모든 공급자 공통 표)

개인 사용 / 상업적 이용 / 웹 화면 표시 / 원본 저장 / 가공 데이터 제공 / 제3자 재배포 / 보관·삭제 의무 — 현재 등급은 [기초 분석서 8장](01-architecture-design.md) 표. 정적 사이트는 브라우저가 JSON을 받으므로 **"클라이언트로 전달되는 파일" 허용 여부**를 8번째 질문으로 추가 [03 검토].

## 목차

### 1. 국내 주가
- 후보: 금융위 주식시세정보(공공데이터포털, 무료, 다음 영업일 13시 이후 [02 진단 공식·발췌]), KRX Open API(비상업 [2차]), KRX·코스콤 계약(비공개 요금)
- 상태: 이용허락범위·자료 시작 연도 **확인 필요**
- 결정 필요: [Q-05] 하루 늦음 감수

### 2. 미국 주가
- 후보: Tiingo(재배포 별도 문의), EODData(견적제), Twelve Data(Grow $79·Pro $229, 예산 초과 [02 진단 공식·발췌]), 사용자 자기 키 방식
- 상태: 월 5만 원 안 공개 표시 **확인된 방법 없음** [03 검토]
- 결정 필요: [Q-06], [Q-07]

### 3. 국내 기업 재무 및 공시
- 후보: OpenDART (재무·배당·공시·기업개황)
- 상태: 영리 이용·출처 표시·호출 한도 **확인 필요**

### 4. 미국 기업 재무 및 공시
- 후보: SEC EDGAR (companyfacts·submissions, 공공 정보 재사용 가능 [02 진단 공식·발췌], User-Agent 선언·초당 10회)
- 상태: 원문 재확인 필요 (이 환경 접속 차단)

### 5. 국내 경제지표
- 후보: 한국은행 ECOS (V1에서 사용 중)
- 상태: 공공데이터포털 '이용허락범위 제한 없음' 표기 [공식·발췌], ECOS 자체 약관 **확인 필요**

### 6. 미국 경제지표
- 후보: FRED
- 상태: **시리즈마다** 원 저작권자 조건이 다름 → 쓸 시리즈 목록을 먼저 정하고 시리즈별 확인

### 7. 공급자별 비용
- 쓸 내용: 공개 가격 / 원화 환산(환율 가정 명시) / 5만 원 안 여부 / 견적 상태 — 초안은 02 진단 4장
- 원칙: 공개 안 된 가격은 추정하지 않음

### 8. 상업적 이용 및 재배포 권한
- 쓸 내용: 공급자 × 7(+1)항목 표를 원문 인용과 확인 날짜로 채우기
- 지금은 V2에서 쓰지 않을 공급자도 기록: Yahoo(개인 라이선스), 네이버 내부 JSON, 구글 뉴스 RSS, faireconomy (V1 전용) → 사용 안 함

### 9. 데이터 공급자 교체 전략
- 초안 [02 진단 8장 + 기초 분석서 6장]: 순서 DART 재무 → EDGAR 재무 → ECOS·FRED → 국장 공공 시세 → 미장(견적대로)
- 쓸 내용: 교체 시 영향 체크리스트(원가격/수정가격, 과거 기간, 식별자, 계정 매핑), 두 공급자 겹치는 기간 대조 방법, 공급자 하나가 끊겼을 때 대체 순서
