# -2easy-stock

KIS(한국투자증권) Open API로 실시간 체결가를 받아 텔레그램으로 알려주는 감시봇, 그리고 계좌 없이 돌아가는 스윙 신호 알림.

## 국장·미장 매매 신호 알림 (계좌 필요 없음)

`swing-signals` 워크플로가 야후 일봉으로 신호를 계산해 텔레그램으로 보내요. 규칙은 수익보다 **하락을 줄이는 쪽**으로
골랐어요 ([docs/conservative-backtest.md](docs/conservative-backtest.md), 코드는 `strategy.py`).

| | 언제 | 규칙 | 백테스트 (2011~) |
|---|---|---|---|
| 국장 | 평일 17:30 | 코스피가 50·200일선 위이고 대형주 40% 이상이 200일선 위일 때만 돌파 후 눌림 종목(변동성 연 45% 이하)을 종목당 10%씩, 5일선 위·10거래일·-7% 손절로 매도. 실적 발표 시즌(1·4·7·10월 20일 ~ 다음 달 중순)엔 새로 사지 않음 | 연 +4.5%, 최대 낙폭 -3.2% (코스피 보유 +8.3%, -44%) |
| 미장 | 화~토 07:30 | S&P500이 200일선 위이고 50일선도 200일선 위이며 변동성이 연 25% 이하면 계좌 50%를 SPY 등 S&P500 ETF로, 아니면 현금 | 연 +5.7%, 최대 낙폭 -9.5% (S&P500 보유 +12.2%, -34%) |

- 하락이 아예 없는 규칙은 없어요. 대신 하락 폭을 지수의 1/3~1/5로 줄이고, 그만큼 수익도 덜 나요.
- 필요한 Secrets: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` (아래 감시봇과 같은 값)
- 신호마다 매매 의견(매수 이유, 손절가, 청산 조건, 위험 요인)이 붙어요. 규칙으로 계산해서 사용료가 없어요
- 바로 확인: Actions → swing-signals → Run workflow (market=both)
- 주문은 하지 않아요. 백테스트 숫자는 과거 결과일 뿐이에요.

### 부서별 보고 (`departments.py`)

신호 알림 끝과 대시보드에 여섯 부서가 한 줄씩 보고해요. 전부 무료 규칙 코드예요.

| 부서 | 하는 일 |
|---|---|
| 스크리닝부 | 대형주 중 200일선 위 종목 수, 오늘 조건 통과 종목 수 |
| 기술적 분석부 | 돌파 뒤 눌림(RSI2), 미장은 50일선·200일선 위치 |
| 펀더멘탈부 | 야후 무료 재무 요약으로 후보 종목 등급(흑자, ROE 8%↑, 부채비율 150%↓, 이익 증가, PER 25배↓). 과거 재무 자료가 무료로 없어 검증을 못 해서 **참고 등급만** 붙이고 규칙은 안 바꿔요 |
| 마켓부 | 지수 추세, 시장 폭(200일선 위 종목 비율), 지수 변동성. 뉴스는 무료로 믿을 만하게 볼 방법이 없어 안 봐요 |
| 리스크관리부 | 비중, 손절, 신규 매수 멈춤 여부 |
| 운용부 | 오늘 가상계좌에 기록할 주문, 실제 주문은 본인 판단 |

강화안은 [docs/desk-backtest.md](docs/desk-backtest.md)에서 백테스트로 골랐어요. 국장은 시장 폭 50%↑ + 변동성 큰 종목 제외로 최대 낙폭 -7.8% → -4.4%,
미장은 S&P500 변동성 25%↑면 현금으로 -10.9% → -9.5%. 도움이 안 된 안(코스피 변동성 필터, 미장 시장 폭)은 넣지 않았어요.

### 내 매매 규칙표 검증

내가 정한 규칙표(200일선 위, 60일선 > 200일선, RSI14 45~60, 거래량 20일 평균 이상, 30/30/40 분할매수·익절,
손절 -2%, 하루·주·월 손실 -1/-2/-4%에서 중단)는 `rulebook.py`에 있어요. 백테스트([docs/rulebook-backtest.md](docs/rulebook-backtest.md))에서
국장 연 -2.3%·최대 낙폭 -50%, 미장 연 -5.1%·최대 낙폭 -56%라 알림 규칙은 그대로 두고, 같은 워크플로가 규칙표를 별도 가상계좌
(`paper/<시장>/rulebook/`)로 매일 기록해요. 텔레그램 알림 끝에 "[규칙표 후보]"가 붙고, 대시보드에 "내 규칙표 검증" 칸이 생겨요.

### 가상매매 기록

같은 워크플로가 신호대로 샀다고 치고 `paper_trade.py`로 기록해요 (국장 70만 원, 미장 500달러, 수수료·세금 반영, 소수점 매수).

- 시가 체결이 있는 날 "[가상매매]" 알림, 매주 금요일 "[가상매매 주간 결산]" (수익률, 최대 낙폭, 승률, 보유 종목, 지수 비교)
- 기록은 `paper/kr/`, `paper/us/`에 워크플로가 직접 커밋해요: `trades.csv`(끝난 거래), `equity.csv`(날마다 평가금액), `state.json`
- 결산을 아무 때나 받기: Actions → swing-signals → Run workflow → paper_summary 체크
- 처음부터 다시 시작하려면 그 시장의 `paper/` 폴더를 지우면 돼요

### 학습팀 (매일 새벽 규칙 다시 맞추기, `learner.py`)

24시간 켜져 있는 AI가 아니라, `learner` 워크플로가 **매일 한국시간 05:00쯤** 2010년부터 오늘까지 시세로 규칙 값을 다시 시험하는
작업이에요. 무료(야후 일봉 + 기존 백테스트 코드)이고 **규칙은 자동으로 바꾸지 않아요.**

- 시험하는 값: 국장 시장 폭(40/50/60%), 종목 변동성 상한(35/45/60%), 손절(-3/-5/-7%), RSI2 눌림 기준(5/10/15) 81개 조합,
  미장 S&P500 변동성 상한(18/20/25/30%), SPY 비중(30/50/70%), 추세선(150/200일) 24개 조합
- 후보 고르기: 최근 5년에서 최대 낙폭이 지금 규칙보다 나쁘지 않고 연수익을 1%p 넘게 포기하지 않는 값 중 수익/낙폭 비율 1등
- 세 관문을 다 통과해야 "바꾸자"고 제안: ① 최근 5년 낙폭 같거나 작고 수익/낙폭 비율 10%↑ ② 2011년~ 전체 낙폭이 1%p 넘게
  나빠지지 않음 ③ 걸어가며 검증(2016년부터 해마다 앞 5년으로 고른 값을 다음 해에 써 보기)이 지금 규칙 고정보다 나쁘지 않음
- 텔레그램: 새 제안이 나온 날 "[학습팀 새 제안]", 매주 토요일 10:00쯤 "[학습팀 주간 보고]"
- 기록: `learning/kr.json`, `learning/us.json`(대시보드에서 읽을 수 있는 최신 결과), `learning/history.csv`(날마다 쌓임),
  `docs/learning-latest.md`(표)
- 바로 받기: Actions → learner → Run workflow
- 2026-10-05 첫 제안(국장 시장 폭 50% → 40%, 손절 -5% → -7%)을 적용했어요. 최근 5년 연 +3.1%·낙폭 -3.8% → 연 +4.6%·낙폭 -3.0%, 2011년~ 연 +4.1%·낙폭 -4.4% → 연 +4.8%·낙폭 -4.8%
- 제안을 적용하려면 프로젝트 스레드에 "학습팀 제안 적용해"라고 말하면 `strategy.py` 값을 바꾸는 PR을 만들어요

### 경기 리포트 (`macro.py`)

무료 시장 지표 7개로 경기 국면을 판정해요. 경고 0~1개 **확장**, 2~3개 **둔화**, 4개 이상 **위축 경고**.

| 경고 | 기준 (야후 일봉) |
|---|---|
| 장단기 금리 역전 | 미국 10년 국채 금리 < 3개월 국채 금리 |
| 금리 급등 | 10년 금리가 6개월 새 +1%p 넘게 |
| 유가 급등 | WTI가 1년 새 +50% 넘게 |
| 원화 급락 | 원·달러 환율이 3개월 새 +5% 넘게 |
| 신용 경계 | 하이일드 채권(HYG)/국채(IEF) 비율이 200일선 아래 |
| 원자재 약세 | 구리/금 비율이 200일선 아래 |
| 공포 지수 | VIX 20일 평균 25 넘음 |

- `macro` 워크플로가 매일 한국시간 06:50쯤 판정을 `paper/macro.json`에 남겨요. 앱 홈 "경기 국면" 칸과 신호 알림의 리스크관리부 보고에 붙어요
- 텔레그램: 월요일 아침 "[경기 리포트]", 판정이 바뀐 날 "[경기 판정 바뀜]". 기준에 가까운 항목은 🟡로 표시해요
- 미국 실업률·삼 법칙·물가·실업수당 청구(FRED, 무료)도 참고로 붙여요. 나중에 고쳐지는 월간 자료라 규칙엔 안 써요
- **매매 규칙은 안 바꿨어요.** 백테스트([docs/macro-backtest.md](docs/macro-backtest.md))에서 경고가 많을 때 매수를 줄이거나 쉬어도
  국장 낙폭은 그대로(-3.2%)였고, 미장은 낙폭이 조금 줄지만 수익이 훨씬 많이 줄어서 경기와 상관없이 비중만 낮춘 것보다 못했어요
- 바로 받기: Actions → macro → Run workflow

### 업종별 호재·악재 (`sectors.py`)

종목(알림 종목 + 넓은 범위, 국장·미장 약 400개)을 한국어 업종 16개(반도체, 2차전지, IT·전자, 자동차, 조선·방산·기계, 금융 …)로 묶어요.

- 업종마다 최근 5·20거래일 등락률 중간값, 지수 대비, 200일선 위 비율, 가장 강한·약한 종목
- 구글 뉴스 RSS(무료)에서 업종 검색어로 최근 7일 제목 5개를 받아 '수혜·호조·사상 최대'는 호재, '우려·부진·규제'는 악재로 세요
- 신호 알림 끝 "[업종별 호재·악재]"(강한·약한 업종 3개씩), 매수 후보 의견에 "업종: …" 한 줄
- 앱 홈 "업종별 호재·악재" 칸: 업종 버튼을 누르면 그 업종의 흐름·뉴스 제목·대형주만 보여 주고, 관심 화면 전체 종목도 같은 업종으로 걸러요
- 종목 화면 "업종과 연관 업종": 그 종목 업종과 공급망·수요로 이어진 연관 업종(`RELATED`, 예: 2차전지 → 자동차·화학·소재·전력)의 흐름·호재·악재, 같은 업종 대형주를 한꺼번에 보여 줘요
- 업종 지도는 `paper/sectors.json` (야후 업종 → 한국어, 어긋나는 대형주는 `OVERRIDES`로 고침). 매주 fundamentals 워크플로가 새 종목만 채워요
- 과거 뉴스를 무료로 모을 방법이 없어 백테스트를 못 하니 **매매 규칙은 안 바꾸고 참고로만** 붙여요

### 고장 감시 (`health.py`)

알림이 안 온 날이 "신호 없음"인지 "고장"인지 구분할 수 있게 해요.

- 자동 작업(swing-signals, telegram-bot, learner, pages, fundamentals)이 실패하면 "[고장]" 알림이 와요. 멈춘 이유를 알면 같이 붙어요.
  15분마다 도는 봇처럼 실패가 이어지면 처음 한 번만 보내요
- 신호 계산 전에 시세를 점검해요. 대형주 30% 넘게 비었거나 지수가 없으면 신호를 내지 않고 멈춰요(가상매매도 같이).
  일부 종목이 비거나, 하루 ±30% 넘게 튀거나, 지수 날짜가 오래됐으면 알림 끝 "[데이터 점검]"에 적어요
- 일요일 10:00 `health` 워크플로가 지난 7일 실행 결과를 세서 "[주간 점검]"을 보내고 `paper/health.json`에 남겨요

### 실적 발표 시즌 (`earnings_backtest.py`)

국장 알림은 분기 실적이 몰리는 1·4·7·10월 20일 ~ 다음 달 중순엔 새로 사지 않아요. 백테스트([docs/earnings-backtest.md](docs/earnings-backtest.md))에서
최대 낙폭 -4.8% → -3.2%, 최악의 해 -0.4% → +1.5%였고(연평균은 +4.7% → +4.5%로 조금 줄어요), 시즌을 1주 앞뒤로 옮기거나 길이를 바꿔도 비슷했어요. 상관없는 달을 쉬면 효과가 없었어요.
매수 후보마다 다음 실적 발표일(야후)도 의견 줄에 붙여요.

### ETF(원화) 가상계좌 (`etf_backtest.py`, `paper/etf/`)

미장 알림과 같은 신호를 국내 상장 ETF로 원화 계좌에서 따라 하는 버전이에요. 전역 뒤 ISA·연금저축 계좌에서 그대로 살 수 있어요.

- S&P500 추세가 살아 있으면 계좌의 50%를 TIGER 미국S&P500(360750)으로, 아니면 현금 (70만 원, 1주 단위, 국장 마감 뒤 신호 → 다음 날 시가)
- 백테스트([docs/etf-backtest.md](docs/etf-backtest.md), 2011~, 상장 전은 SPY×환율로 대신): 연 +7.1%, 최대 낙폭 -8.4%
- KODEX 200을 같이 드는 안은 2026-07 코스피 급락 때문에 낙폭이 커서(-26~-32%) 뺐어요
- 국장 실행(17:30) 때 같이 기록하고, 체결이 있으면 "[가상매매 ETF(원화)]" 알림이 와요

### 실전 전환 판정표 (`readiness.py`)

"언제 진짜 돈을 넣어도 되나"를 가상계좌 숫자로 판정해요. 금요일 결산 끝과 대시보드 성과 화면에 나와요.
기간 60거래일 이상, 최대 낙폭이 백테스트의 1.5배 안, (국장만) 끝난 거래 10건 이상, 지난 주간 점검 전부 정상.
전부 통과하면 소액(예: 10만 원)으로 시작해 볼 만한 단계라고 알려 줘요. 수익률은 관문에 넣지 않았어요.

### 넓은 범위 후보 (`wide.py`, 참고)

알림 종목 48개는 2015년 기준으로 고정이라 그 뒤 커진 회사가 빠져 있어요. 같은 조건을 지금 코스피 시가총액 상위 200개(우선주 제외, 2026-10 100개에서 늘림)로 넓혀
"[넓은 범위 후보 · 참고]"로 보여 줘요. 지금 목록으로는 과거를 공정하게 백테스트할 수 없어서 가상계좌엔 넣지 않고,
추천 종목 성과(`picks.csv`의 src=wide)로 실제 결과만 쌓아요.

### 왜 움직였나 (`movers.py`, 추정)

알림 끝 "[왜 움직였나 · 추정]"과 대시보드 홈 카드에 최근 5거래일 많이 오른 종목 5개, 많이 내린 종목 3개(±3% 넘게)와 이유를 붙여요.
국장은 알림 48개 + 코스피 상위 200개(약 200종목), 미장은 알림 48개 + 시가총액 상위 150개(약 200종목)를 봐요.
미장 150개는 이 칸에만 쓰고 신호·가상계좌에는 안 넣어요. 이유는 전부 무료 규칙이에요.

- 시장 영향: 같은 기간 코스피·S&P500과 비교해서 시장이 다 오른 건지, 이 종목만 오른 건지
- 업종·테마: 그 전 120일 동안 같이 움직이던 종목 3개도 같이 올랐는지
- 거래량: 최근 5일 중 가장 많은 날이 그 전 20일 평균의 몇 배인지, 하루 ±5% 넘게 움직인 날, 52주 신고가
- 뉴스 제목: 구글 뉴스 RSS(무료, 키 없음)의 최근 7일 제목에서 실적·수주·신제품·증권가 전망·유가·AI·2차전지·정책 같은 낱말을 찾아요

뉴스는 자동 수집이라 틀릴 수 있어요. 이유는 짐작이고, 사기 전에 기사 원문을 꼭 확인하세요.

### 내 자산 합계

대시보드 홈 성과 칸에 가상계좌 셋(국장·미장·ETF)을 원화로 합친 금액, 현금 비중, 달러 비중이 나와요 (환율은 야후 KRW=X 최근 값).

### 폰 대시보드 (GitHub Pages)

`site/` 웹앱이 오늘의 신호, 가상계좌 수익률 그래프(지수와 비교), 보유 종목, 최근 거래, 지수 추세를 보여 줘요.
아래쪽 버튼으로 화면을 바꿔요: **홈**(오늘 신호·관심종목·성과·지수 요약), **신호**(매수 후보·부서 보고·규칙표 후보),
**관심**(★로 고른 종목의 시세·3개월 추세선), **성과**(추천 종목 성과·가상계좌·보유·거래), **차트**(지수 캔들·보조지표).
목록에서 종목을 누르면 **종목 화면**(3년 차트·보조지표, 재무제표)이 열려요.

- 관심종목은 알림이 보는 대형주(국장 48개, 미장 48개 + SPY) 중에서 ★로 골라요. 목록은 그 폰 브라우저에만 저장돼요.
  목록에 없는 종목은 아래 '종목 검색'에서 텔레그램 봇으로 넣어요
- 추천 종목 성과: 같은 워크플로가 날마다 추천 종목(알림 매수 후보·SPY 매수 신호, 내 규칙표 후보)을 `paper/<시장>/picks.csv`에
  남기고(`track.py`), 추천일 종가에서 5·10·20거래일 뒤 평균 수익률을 같은 기간 지수와 비교해 보여 줘요. 종목별로 추천일부터
  날마다 수익률 그래프도 있어요. 같은 종목이 10거래일 안에 다시 후보가 되면 처음 추천만 세요
- `picks.csv`가 없으면 지난 120거래일을 지금 규칙으로 다시 계산해서 채워요 (`replay=1`, 그날 실제로 보낸 알림은 아님)
- 차트 보조지표: 이동평균선(50·200일선), 볼린저밴드(20개 캔들 평균 ± 표준편차 2배), 거래량(막대 + 20개 평균선),
  RSI(14)를 버튼으로 켜고 꺼요. 지금 보는 캔들(일·주·월·년봉)로 계산하고, 켠 지표는 그 폰 브라우저가 기억해요
- 화면 효과: 화면을 바꾸면 카드가 부드럽게 떠오르고(종목·검색 화면은 옆에서 밀려 들어와요), 평가금액·수익률·종목 가격은
  0부터 올라가며 나타나요. 새 신호가 오면 '새 신호' 표시가 붙고 신호 카드가 한 번 반짝여요. 할 일이 있는 날(국장 매수 후보,
  미장 매수 신호)은 초록, 미장 매도 신호는 주황 카드예요. 폰 설정에서 '동작 줄이기'(아이폰: 손쉬운 사용 → 동작)를 켜면 움직임은 꺼요
- 종목 화면: 3년치 일봉 차트(보조지표 같이)와 재무제표(PER·PBR·시가총액·배당수익률·ROE·부채비율, 연간·분기
  매출·영업이익·순이익). 시세는 pages 배포 때 `stock_pages.py`가 야후에서 받아 종목별 파일(`stocks/<시장>/<코드>.json`)로
  만들고, 재무는 `fundamentals` 워크플로가 매주 토요일 `paper/<시장>/fundamentals.json`에 저장해요
  (`fundamentals.py`). 한국 종목은 야후가 PER·PBR을 비워 둘 때가 많아서 최근 4분기 순이익·자본총계로 계산해요
`pages` 워크플로가 `dashboard.py`로 `paper/` 기록을 `data.json`으로 묶어 올리고, swing-signals가 끝날 때마다 다시 올려요.

- 처음 한 번: Settings → Pages → Source를 **GitHub Actions**로 → Actions → pages → Run workflow
- 주소: `https://thd051130-crypto.github.io/-2easy-stock/` → 폰 브라우저 메뉴에서 "홈 화면에 추가"하면 앱처럼 열려요
- GitHub Pages 사이트는 저장소가 비공개여도 누구나 주소로 볼 수 있어요 (무료 계정은 공개 저장소에서만 Pages를 켤 수 있어요)
- 새 화면이 배포되면 앱을 열 때 서버에 새 버전이 있는지 확인해서 바로 보여 줘요. 앱을 열어 둔 채였으면 다시 볼 때 한 번 새로고침돼요
- 미리 보기: `python dashboard.py --out _site && python -m http.server -d _site`

### 종목 검색, 텔레그램으로 관심종목 넣기·가격 알림

- 앱 위쪽 돋보기로 국장(코스피·코스닥·국내 ETF)과 미장(시가총액 2억 달러 이상 주식, 순자산 큰 ETF 1,000개) 상장 종목을
  찾아요. 한글·영문·코드 다 되고 '하이닉스', '삼성sdi', '코덱스 200', '슈드'처럼 일부만 쳐도 돼요. 종목 목록
  (`paper/symbols/kr.json`, `us.json`)은 `fundamentals` 워크플로가 매주 토요일 `symbols.py`로 야후에서 새로 받아요
- 대시보드에 없는 종목은 '추가'를 누르면 텔레그램이 열리고, 봇 화면에서 시작(START)을 누르면 봇이 `paper/watch.json`에
  넣어요. 그다음 배포부터 그 종목도 시세·차트·재무제표가 생기고 관심 화면 ★에 들어가요. 화면에만 쓰고 매매 신호·가상매매에는
  안 넣어요 (시장마다 30개까지)
- 종목 화면 '가격 알림'에 가격을 넣으면 그 가격에 닿을 때 텔레그램으로 알려 줘요 (`paper/alerts.json`, 20개까지). 최근 종가보다
  높으면 '이상', 낮으면 '이하' 알림이고, 5분봉 고가·저가로 확인해서 잠깐 닿은 것도 잡아요. 국장 시세는 야후가 20분쯤 늦게 줘요
- `telegram-bot` 워크플로(`bot.py`)가 15분마다 돌면서 그사이 봇에게 온 메시지를 처리하고 알림 가격을 확인해요. 서버가 없어서

## 폰만으로 연결 확인 (GitHub Actions)

1. 텔레그램 @BotFather에서 `/newbot` → 봇 토큰 받기, 만든 봇에게 아무 메시지나 보내기
2. 모바일 브라우저로 저장소 Settings → Secrets and variables → Actions에 `KIS_APP_KEY`, `KIS_APP_SECRET`, `TELEGRAM_BOT_TOKEN` 등록
3. Actions → kis-live-check → Run workflow, mode=`chat-id` → 로그에 나온 숫자를 `TELEGRAM_CHAT_ID` Secret으로 등록
4. mode=`test-telegram` → 텔레그램에 테스트 메시지가 오면 성공
5. mode=`check` → 승인키 발급 확인 (모의투자 앱키면 kis_env=mock, 실전이면 real)
6. 평일 09:00~15:30에 mode=`live` → 로그에 체결이 찍히고 텔레그램에 "[실시간 연결 확인]" 알림

## PC에서 연결 확인 (5단계)

```bash
pip install -r requirements.txt
cp .env.example .env        # 앱키/시크릿, 텔레그램 토큰 채우기

python realtime_monitor.py --check          # 1. 승인키 발급 확인
python realtime_monitor.py --chat-id        # 2. 봇에게 아무 말 보낸 뒤 실행 → TELEGRAM_CHAT_ID 확인해서 .env에
python realtime_monitor.py --test-telegram  # 3. 텔레그램 테스트 메시지
python realtime_monitor.py --raw            # 4. 장중(평일 09:00~15:30) 실행 → 체결 수신 + 종목별 첫 체결 알림
```

- 앱키는 KIS Developers(apiportal.koreainvestment.com)에서 발급. 모의투자 앱키와 실전 앱키는 따로라 `KIS_ENV`를 맞춰야 해요.
- 텔레그램 봇 토큰은 @BotFather에서 `/newbot`으로 발급.
- `--raw`로 찍힌 원문이 이상하게 파싱되면 그 줄을 그대로 공유해 주세요.
